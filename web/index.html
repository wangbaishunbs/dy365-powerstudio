使用说明

真机连接
使用 Edge / Chrome 打开本页面,设备通过 USB 连接电脑后,点击「选择串口」选中对应 COM 口(CH340/CP210x 等),选择波特率(默认 9600、8N1),点击「连接」。地址填 0 表示不校验。

模拟器
没有硬件时点击顶部「模拟器」即可体验全部功能:实时曲线、恒压/恒流切换、保护、扫描、记录导出。拖动「模拟负载电阻」滑块观察 CV→CC 转换。

数据导出
「数据记录」支持导出 CSV(UTF-8 BOM,Excel 可直接打开)与 Excel(.xls)。文件名格式与官方软件一致:Power_Log_时间戳。

兼容性说明
本工具完整复刻官方上位机协议:帧头 A5 5A、CRC16(Modbus 变体,末异或 FFFF)、204 字节状态结构体、功能码 FF/FC/FD。与官方 Power Supply V1.0.0.1 行为一致,可混用。

提示:若浏览器提示串口权限,请允许;串口被其他程序(如官方上位机)占用时无法打开。
